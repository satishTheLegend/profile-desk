# Dependency and license inventory

`dependencies.csv` records actual resolved Dart packages (runtime and development), local license-file hashes and consuming packages. Regenerate after `scripts/bootstrap.sh` with `python3 scripts/dependency_inventory.py`. Exact versions/checksums remain in each `pubspec.lock`; do not hand-edit locks. SDK packages share the Flutter SDK BSD license when no per-package file exists; missing license files require review before distribution.

Native direct dependencies: AndroidX WebKit1.17.1 (Apache2), Kotlin compiler2.4.0 and kotlinx-coroutines-android1.10.2 (Apache2), Android Gradle Plugin9.1.0 (Apache2). Test only: JUnit4.13.2 (EPL1), Robolectric4.16.1 (MIT), AndroidX test1.7.0/JUnit extension1.3.0 (Apache2), Mockito5.0.0 (MIT). Android transitive graph is retained in `evidence/build/android-dependencies.txt` and the final lock-generation graph in `evidence/build/android-dependencies-locked.txt`. iOS implementation uses OS WebKit/SQLite/Security/LocalAuthentication and Flutter, with no third-party browser-storage wrapper. Pigeon29.0.10 generates the bridge. Tabler SVGs include their MIT notice in `apps/mobile/assets/icons/LICENSE`. Lottie3.6.1 renders three original bundled JSON illustrations; its resolved dependencies are included in the Dart inventory. Manrope’s variable font is bundled under the SIL Open Font License with its full notice at `apps/mobile/assets/fonts/Manrope-OFL.txt` and an in-app license entry. Fonts and animations load locally.

This inventory does not assert that dependencies have no vulnerabilities or that all notices have legal approval. Release owner reviews full resolved licenses/advisories before distribution. Run `flutter pub outdated` and review official AndroidX/Flutter/Xcode releases on a controlled update branch; rerun bridge generation, static/tests/native storage and actual-service compatibility on changed engines. Keep the original passing lockfiles for comparison. Do not upgrade WebView dependencies just to bypass failed isolation evidence.

Gradle9.3.1's wrapper distribution is SHA-256 pinned to the checksum published at `https://services.gradle.org/distributions/gradle-9.3.1-all.zip.sha256`. The repository-owned app and session_engine Gradle configurations have dependency locks, generated with `./gradlew :app:dependencies :session_engine:dependencies --write-locks`. Normal production and isolated QA builds passed without --write-locks. Flutter engine coordinates (`io.flutter:*`) are excluded from these locks because the pinned SDK selects them by target ABI. This covers the remaining resolved module configurations, not universal buildscript/plugin/composite dependency verification. Cryptographic dependency verification and advisory review remain distinct release work. The regenerated CSV records the current resolved Dart/SDK/workspace entries for production and shared tests. The isolated QA fixture retains separate Dart and Android locks with the integration-test SDK dependency; that native plugin is absent from production.
