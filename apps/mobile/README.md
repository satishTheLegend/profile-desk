# Profile Desk mobile shell

Run from the root using `scripts/bootstrap.sh` and `scripts/check.sh`, or use
`flutter run --flavor development` here. Android/iOS native engines are local
workspace packages. English ARB strings are in `lib/l10n/app_en.arb`.

The root README, architecture and evidence ledgers define supported behavior and
remaining validation. This directory is not a web application or public site.
